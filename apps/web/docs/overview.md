# web

The storefront for a Medusa backend — regions, catalogue, search, cart, checkout and accounts (Next.js on Cloudflare Workers + Static Assets via @opennextjs/cloudflare, per environment; a bundled sample catalogue until a backend is connected)

A Cloudflare Worker with Static Assets (server rendering plus static files), deployed per environment by its CI lane.

|              |                                                                                                                    |
| ------------ | ------------------------------------------------------------------------------------------------------------------ |
| Type         | `cloudflare-workers-assets-turbo`                                                                                  |
| Source       | `apps/web`                                                                                                         |
| Package      | `@app/web`                                                                                                         |
| Environments | `dev`: `verify` · `stage`: `verify`, `deploy` on a push to `main` · `prod`: `verify`, `deploy` on a push to `main` |
